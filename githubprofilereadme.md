### Selected Projects

- **[Eigendrum](https://eigendrum.com)** ([source](https://github.com/BaselAshraf81/eigendrum)): In-browser finite element acoustics solver computing 2D Dirichlet Laplacian spectra on drawn outlines with real-time modal synthesis (no audio samples). Solves 2,051 unknowns in ~800 ms in a Web Worker.
  - **150★ on GitHub** &middot; **[DOI: 10.5281/zenodo.22019539](https://doi.org/10.5281/zenodo.22019539)**
  - Featured on [Hacker News](https://news.ycombinator.com/item?id=49305250) (front page twice), [Wikipedia](https://en.wikipedia.org/wiki/Hearing_the_shape_of_a_drum#External_links), [kottke.org](https://kottke.org/26/08/0049489-eigendrum), [r/InternetIsBeautiful](https://www.reddit.com/r/InternetIsBeautiful/comments/1vqhylx/eigendrum_draw_a_shape_and_hear_it_as_a_drum/), and 52+ international publications in 8 languages.

- **[LayoutSans](https://github.com/BaselAshraf81/layout-sans)** ([npm](https://www.npmjs.com/package/layout-sans)): Headless flex and grid layout engine written in pure TypeScript in ~17 kB gzipped with zero dependencies and no WASM (runs 2 to 3 times faster than Meta's Yoga). Includes canvas text drag selection, Ctrl+F search, and screen-reader accessibility tree generation.

- **[Prolific Tea](https://prolifictea.com)**: Researcher review and pay transparency platform for academic study participants. Full-stack Next.js, companion Chrome extension for real-time study request interception, PWA push notifications, and 100,000+ page views.

- **[fastemporal](https://docs.rs/fastemporal)** ([crates.io](https://crates.io/crates/fastemporal)): Pure Rust reimplementation of Luxon and TC39 Temporal datetime APIs with zero heap allocations in hot paths. Passes 332 ported tests and benchmarks 7 to 216 times faster than JS Luxon.

- **[Nextron PR #531](https://github.com/saltyshiomix/nextron/pull/531)**: Upgraded Electron + Next.js framework to Next 16 and React 19 with Turbopack compatibility across 33 files (+1,218 / -416 lines), released as `nextron@9.6.0`.

- **[holystitch](https://github.com/BaselAshraf81/holystitch)**: Model Context Protocol (MCP) server compiling Google Stitch designs directly into React and Next.js component trees via native API calls without consuming LLM inference tokens.

- **[Photophane](https://baselashraf.com/work/photophane.html)** ([generator](https://baselashraf81.github.io/photophane/)): Computational optics engine solving inverse optimal transport to machine 3D acrylic caustic relief plates (10.97 mm depth) that project focused photographs via refracted light.
